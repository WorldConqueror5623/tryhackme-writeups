A collection of my TryHackMe room writeups documenting reconnaissance, enumeration, exploitation, and privilege escalation techniques in controlled lab environments.

This repository contains walkthroughs and notes from rooms completed on TryHackMe. The goal is to document methodology, reinforce learning, and build a portfolio of practical cybersecurity experience.
